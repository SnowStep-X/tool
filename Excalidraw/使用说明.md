# Excalidraw 本机白板

## 打开与关闭

- 双击同目录的 `启动白板.command`，它会启动 Docker 和白板，并用默认浏览器打开。
- 白板运行后，访问 <http://localhost:8787>。
- 双击 `停止白板.command` 可以停止白板服务。

## 开始画图

1. 从顶部工具栏选择矩形、菱形、椭圆或箭头，在画布上拖动绘制。
2. 双击图形输入文字；文字工具可以添加独立说明。
3. 用箭头连接图形，选中对象后可调整颜色、线条和背景等属性。
4. 按住空格拖动平移画布，使用画布中的缩放按钮调整视图。
5. 按 Command+Z 撤销；选中对象后按 Delete 删除。

## 保存与导出

- 绘图会保存在当前浏览器的本地数据中。请固定使用同一个浏览器和地址。
- 通过左上角菜单保存/导出 `.excalidraw` 文件，可以继续编辑、备份和迁移。
- 需要放进文档或演示稿时，导出 PNG 或 SVG。
- 浏览器本地数据不是文件备份。清理网站数据或使用无痕窗口可能造成绘图丢失，请及时导出重要文件。

## 安装范围

此安装运行 Excalidraw 官方 Docker 客户端，只监听本机 127.0.0.1:8787。
未额外部署实时协作和分享后端；多人协作可以使用官方在线版 <https://excalidraw.com>。
